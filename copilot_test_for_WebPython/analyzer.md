# analyzer.md

## 目的
`analyzer.md` ファイルの目的は、`TestcaseXXX.xlsx` ファイルを解析することです。`TestcaseXXX.xlsx` ファイルには複数のページブロックが含まれており、各ページブロックはWebページの操作手順を記述しています。

## ファイル形式
`TestcaseXXX.xlsx` ファイルの内容形式は以下の通りです：

| 0            | 1                    |
|--------------|-----------------------|
| URL          | http://example.com    |
| identifier   | value                 |
| 名前         | 張三                  |
| 性別         | 男                    |
| 国           | 中国                  |
| オプション   | option_value          |
| 提出         | クリック              |
|              |                       |
| URL          | 前ページに移動        |
| identifier   | value                 |
| 名前         | 李四                  |
| 性別         | 女                    |
| 国           | アメリカ              |
| オプション   | another_option_value  |
| 提出         | クリック              |
|              |                       |
| URL          | http://anotherpage.com|
| identifier   | value                 |
| 名前         | 王五                  |
| 性別         | 男                    |
| 国           | 日本                  |
| オプション   | third_option_value    |
| 提出         | クリック              |

## 解析ルール

### ページブロック
- **URL行**：各ページブロックの最初の行はURL行で、URL文字列が含まれています。URL文字列が記載されている列の右側の列には、実際のURLアドレスや「前ページに移動」などの文字列が記載されている場合があります。
- **キーバリューテーブル**：URL行の下の複数行（空行まで）はキーバリューテーブルです。キーバリューテーブルの最初の行はヘッダーで、`identifier` と `value` の2列が含まれています。`identifier` 列には操作するコントロールの名前が記載され、`value` 列にはそのコントロールに対する操作値が記載されています。

### 操作モジュール
- 1つの `TestcaseXXX.xlsx` ファイルには複数の操作モジュールが含まれている場合があります。各操作モジュールの間には少なくとも1行の空行があります。
- 各操作モジュールの最初の行はURL行で、そのページを開くまたはジャンプするためのURLを指示します。URL文字列は実際のネットワークアドレスである場合もあれば、前のページの対応するジャンプ指示である場合もあります。
- 各操作モジュールの2行目は通常 `identifier` と `value` で、ページ内で操作する必要があるコントロールとそのコントロールに対して行う操作を指します。

### identifier 列
- `identifier` 列に記載されている内容には以下の可能性があります：
  1. 完全かつ正確なコントロール名。
  2. 大まかなコントロール名（ページ内で最も可能性の高いコントロールを検索する必要があります）。
  3. コントロールの機能（ページを具体的に分析して最も適切なコントロールを特定する必要があります）。
- `identifier` に基づいてページ内の対応するコントロールを見つけ、そのコントロールに対して相応の操作を行う必要があります。`identifier` はWebページのinput名である場合もあれば、そのWebページのlabel名である場合もあり、部分一致の名前である場合もあります。さらには、同じ意味の別名である場合もあります。そのため、ユーザーが操作しようとしているページコントロールを模糊マッチングまたはインテリジェント推測する必要があります。

### value 列
- `value` 列には、そのコントロールに対する操作値が記載されています。操作値には、入力フィールドの入力値、ラジオボタンの選択値、チェックボックスの操作値、ドロップダウンリストの選択値、ボタンのクリック操作などが含まれます。

## 解析手順
1. `TestcaseXXX.xlsx` ファイルを開く。
2. ファイル内容を行ごとに読み取り、各ページブロックを識別する。
3. 各ページブロックに対して、ループ処理を行う：
   - URL行を読み取り、ページのURLまたはジャンプ指示を取得する。
   - キーバリューテーブルのヘッダーを読み取る。
   - キーバリューテーブルを読み取り、操作する必要があるコントロールとその操作値を取得する。
   - `identifier` 列の内容に基づいて、インテリジェントに推測し、ページ内の対応するコントロールを見つける。
   - `value` 列の内容に基づいて、コントロールに対して相応の操作を行う。
   - 空行に遭遇した場合、現在のページブロックが終了したことを示し、次のページブロックの処理を続ける。

## 例
仮に `Testcase001.xlsx` ファイルの内容が以下の通りであるとします：

| 0            | 1                    |
|--------------|-----------------------|
| URL          | http://example.com    |
| identifier   | value                 |
| 名前         | 張三                  |
| 性別         | 男                    |
| 国           | 中国                  |
| オプション   | option_value          |
| 提出         | クリック              |
|              |                       |
| URL          | 前ページに移動        |
| identifier   | value                 |
| 名前         | 李四                  |
| 性別         | 女                    |
| 国           | アメリカ              |
| オプション   | another_option_value  |
| 提出         | クリック              |
|              |                       |
| URL          | http://anotherpage.com|
| identifier   | value                 |
| 名前         | 王五                  |
| 性別         | 男                    |
| 国           | 日本                  |
| オプション   | third_option_value    |
| 提出         | クリック              |

解析手順は以下の通りです：
1. 最初の行を読み取り、URL行として識別し、URLは `http://example.com` です。
2. 2行目を読み取り、キーバリューテーブルのヘッダーとして識別します。
3. 3行目から7行目を読み取り、キーバリューテーブルとして識別し、以下のキーバリューのペアが含まれています：
   - 名前: 張三
   - 性別: 男
   - 国: 中国
   - オプション: option_value
   - 提出: クリック
4. 8行目を読み取り、空行として識別し、最初のページブロックが終了したことを示します。
5. 9行目を読み取り、URL行として識別し、URLは `前ページに移動` です。
6. 10行目を読み取り、キーバリューテーブルのヘッダーとして識別します。
7. 11行目から15行目を読み取り、キーバリューテーブルとして識別し、以下のキーバリューのペアが含まれています：
   - 名前: 李四
   - 性別: 女
   - 国: アメリカ
   - オプション: another_option_value
   - 提出: クリック
8. 16行目を読み取り、空行として識別し、2番目のページブロックが終了したことを示します。
9. 17行目を読み取り、URL行として識別し、URLは `http://anotherpage.com` です。
10. 18行目を読み取り、キーバリューテーブルのヘッダーとして識別します。
11. 19行目から23行目を読み取り、キーバリューテーブルとして識別し、以下のキーバリューのペアが含まれています：
    - 名前: 王五
    - 性別: 男
    - 国: 日本
    - オプション: third_option_value
    - 提出: クリック
12. 24行目を読み取り、空行として識別し、3番目のページブロックが終了したことを示します。

以上の解析手順により、各ページブロックのURLとキーバリューテーブルを取得し、`identifier` と `value` 列の内容に基づいてページに対して相応の操作を行うことができます。
